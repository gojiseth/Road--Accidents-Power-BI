# Road--Accidents-Power-BI
## Project Overview
Power BI dashboard analyzing road accident data to identify patterns, high-risk areas, and causes. Built to demonstrate data cleaning, DAX calculations, and interactive dashboard design.

## Dataset
- **Source**: Road Accident Records
- **Records**: 195.7k Total Casualties analyzed
- **Period**: current year CY vs Previous Year PY cmparison

## Key Insights
- **Total Casualties**: 195.7K
- **Total Accidents**: 144.4K 
- **Serious Casualties**: 27.0K
- **Slight Casualties**: 165.8K
- **CY Fatalities**: 2.9K
- **YoY Growth**: CY increased 11% vs PY with 2.9K fatalities
- **Main Drivers**: Motorcycles for incidents, single carriageway roads
- **Pattern**: 84.7% of total are low-severity crashes but massive strain on services
  
## Dashboard Features
- KPI cards for Total Accidents, Fatalities, Injuries
- Interactive map showing accident hotspots
- Bar chart: Accidents by Vehicle Type
- Line chart: Monthly/Yearly accident trends
- Slicers: Filter by Year, Location, Severity
- Slicers: Casualties by Road Type, Casualties by Severity

## Tools Used
Power BI | DAX | Data Cleaning | Excel
